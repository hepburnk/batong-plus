# 바통⁺ (Batong Plus) — AI 업무 인수인계

> 자료만 넣으면 7단 인수인계서·완료도 점수·후임자 Q&A까지 한 번에.
> 서버 없이 브라우저에서만 동작하는 공공기관용 업무 인수인계 웹앱입니다.

행정안전부 「공공 AI 대전환 챌린지」 지정과제 **업무바통(인수인계)** 계열 도구의 기본 흐름
(전임자 자료 업로드 → 인계서 초안 생성)을 넘어, **개인정보 보호 · 정량 점수 · 후임자 질의응답 · 원클릭 배포**까지
한 화면에서 끝내도록 만든 순수 HTML/CSS/JS 웹앱입니다. 빌드 도구도, 서버도, 설치도 필요 없습니다.

## 바로 쓰기

1. `index.html`을 브라우저로 연다 (또는 GitHub Pages 주소로 접속)
2. 「천안의료원 콜센터장」 또는 「공공기관 행정담당자」 샘플을 누른다
3. **인수인계서 생성**을 누른다 — 끝

자료는 ① 텍스트 붙여넣기 ② 파일 끌어다 놓기(.txt `.md` `.csv` `.log` `.json`, 여러 개 동시)
③ 샘플 원클릭 — 세 가지 방식으로 넣을 수 있고, 여러 자료를 합쳐 한 장의 인계서로 만듭니다.

## 7단 구조 인수인계서 (자동 생성)

| | 항목 | 자동으로 해 주는 일 |
|---|---|---|
| ① | 핵심 업무 요약 | 담당 업무·규모·협업 체계 정리 + 핵심 수치(KPI) |
| ② | 진행 중·미완료 과제 | 문장에서 **마감일을 읽어 D-Day 자동 계산**, 우선순위(상/중/하) 정렬 |
| ③ | 반복 루틴 캘린더 | 매일·매주·매월·매분기·매년 분류, **다음 예정일**과 월간 캘린더 표시 |
| ④ | 이해관계자·비상연락망 | 직위·이름·전화·내선·메일을 카드로 분리 추출 |
| ⑤ | 트러블슈팅 FAQ | “증상 → 조치” 문장을 질문/답 카드로 변환 |
| ⑥ | 인수자 첫 7일 온보딩 | 계정·자료 위치·인사·급한 과제·FAQ 순으로 **체크리스트** 자동 구성 |
| ⑦ | 리스크·주의사항 | 개인정보·감사·청탁금지 등 **중대/주의** 로 구분 |

## 기존 ‘업무바통’류와 다른 점

1. **개인정보를 처리 전에 먼저 가립니다** — 주민번호·전화·이메일·계좌·카드·사업자번호를 브라우저에서 자동 탐지해
   부분/전체 마스킹. 마스킹한 텍스트만 AI로 보내고, 화면 표시도 가린 상태가 기본입니다.
2. **점수로 끝나지 않고 “무엇이 빠졌는지”를 문장으로 알려 줍니다** — 인계 완료도 100점제 + 결재선·비상연락처·
   비밀번호 인계 방법·자료 위치 등 10개 항목 누락 경고.
3. **후임자가 바로 물어볼 수 있습니다** — 생성된 인계서를 근거로 답하는 Q&A 패널. 답변마다 **근거 문단과 출처**를 함께 표시.
4. **API 키 없이 100% 동작** — 내장 파싱 엔진만으로 모든 기능이 완성됩니다. 원하면 자신의 OpenAI/Gemini 키를
   브라우저(localStorage)에만 넣어 한 번 더 정밀 분석할 수 있습니다.
5. **원클릭 내보내기** — 인쇄/PDF, Word(.doc), Markdown 복사, JSON 저장. 공문·보고서에 바로 붙일 수 있습니다.

## 개인정보·보안

- 모든 분석은 **브라우저 안에서** 실행됩니다. 자료가 서버로 전송되지 않습니다.
- API 키를 등록한 경우에만, 사용자가 「AI 정밀 분석」을 누를 때 마스킹된 텍스트가 해당 제공사로 전송됩니다.
- 키는 `localStorage`에만 저장되며 「키 삭제」로 언제든 지울 수 있습니다.
- 공유 PC에서는 작업 후 「새로 작성」으로 저장된 자료를 지우세요.

## GitHub Pages 배포

```bash
# 1) 새 저장소 만들기
gh repo create hepburnk/batong-plus --public --source=. --remote=origin --push

# 2) Pages 켜기 (main 브랜치 루트)
gh api -X POST repos/hepburnk/batong-plus/pages \
  -f 'source[branch]=main' -f 'source[path]=/'

# 3) 주소 확인
# https://hepburnk.github.io/batong-plus/
```

정적 파일만 있으므로 별도 설정이 필요 없습니다(`.nojekyll` 포함).
